# Analysis of Amazon India Sales Data 

# About the Project
This project analyzes sales data for clothing items during the summer season, from April through June, on an e-commerce platform called Amazon. The purpose of this project is to identify which clothing items are purchased most frequently by consumers and which are purchased least frequently during the summer season in India, as well as to analyze monthly revenue during the summer season.

# Datasets
Source: Kaggle - Amazon India Fashion Sale 
Period: April–June 2022
Data Set Size: 128,975 transactions

# How to run
1. Install the required libraries: pip install -r requirements.txt
2. Run the dashboard: streamlit run analis_data.py

# Program Structure
-DataLoader = Retrieves the entire dataset from a CSV file
-DataCleaner = Organizes and cleans the entire dataset from the CSV file
-DataAnalyze = Analyzes all the data that has been organized from the CSV file
-DataVisualizer = Converts the analysis results into data that can be visualized using the Streamlit library

# Hasil Analisis
-Revenue peaked in April
-The best-selling product during that period was the kurta (traditional Indian clothing)
-Sales rose at the beginning of summer and declined toward the end of summer
